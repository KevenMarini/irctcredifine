# irctcredifine

A fully functional, modern redesign of the Indian Railway Catering and Tourism Corporation (IRCTC) web portal with Swiss-inspired typography, neo-brutalist accents, and interconnected railway services.

## ✨ Features
- **Train Booking & Live Availability**: Instant search with station autocomplete, class filters (1A, 2A, 3A, CC, EC, SL), quota selection, and timetable stoppage drawers.
- **Dynamic Booking & Passenger Details**: Add up to 6 passengers, 1-click import from Master List, live fare calculation (catering, insurance, GST), and simulated payment gateway (IRCTC E-Wallet, Loyalty Points, UPI, Cards).
- **Interactive PNR Enquiry & Cancellation**: Live PNR status lookup, high-fidelity printable Electronic Reservation Slip (ERS) ticket with QR code, and ticket cancellation with automated wallet refunds.
- **Master List Management**: Save, edit, and manage frequent traveler profiles with verified ID cards.
- **SBI Railway Loyalty Rewards**: Point balance tracker, ledger, and instant redemption to E-Wallet cash.
- **Tourism & Luxury Trains**: Day-by-day itineraries and bookings for Maharajas' Express and spiritual circuits.
- **Reservation Charts & Vacancy Viewer**: Visual coach layouts showing available seats in green.
- **Food on Track (E-Catering)**: Station meal orders delivered to passenger train seats.
- **Retiring Rooms & Pods**: Station executive suites and pod reservations.
- **IRCTC E-Wallet**: Balance top-up and instant 1-click checkout.

## 🚀 Getting Started
Open `index.html` directly in your browser or run a local HTTP server:
```bash
python -m http.server 8000
```
Navigate to `http://localhost:8000` in your web browser.
